# 英语字典·生词本

> **适用版本**：`1.4.0`　|　**最后核对**：2026-09-03

TimeWrite 在 v1.4.0 内置了「英语字典 · 生词本」插件：把阅读 / 写作时遇到的生词**集中收录 → 智能复习 → 逐步掌握**，数据全部保存在本机 `time_write.db`（`vocab_words` / `vocab_reviews` 表），离线可用。

## 打开方式

- 书库首页右上角按钮组中点击**「英语字典」**（玫红渐变按钮），打开独立悬浮窗口
- 按钮右侧角标实时显示**今日待复习词数**；窗口未打开时有待复习词时角标为红色高亮
- 窗口可在各页面之上自由拖动，关闭后按钮回到未激活态

## 窗口布局

顶部顶栏自左向右：

| 区域 | 说明 |
|------|------|
| 标题 | 「英语字典 · 生词本 · 艾宾浩斯复习」 |
| 离线词库状态 | 已安装显示词条规模（如「离线词库 · 46.8 万词」）；未安装时高亮提示，点击可直接导入 |
| 朗读设置 | 配置语音合成 API Key 与音色（见下「语音朗读」） |
| 今日摘要 | 「待复习 n」（有到期词时为红色）/「今日复习已清空」 + 「已复习 n 次」 |

下方为三个页签：**生词本**、**今日复习**（有到期词时显示数量徽标）、**统计**。窗口打开时若今日有待复习词，会自动进入复习页。

## 离线词典（可选，强烈推荐）

- 顶栏点击词库状态按钮 → 选择 **ECDICT 离线词库**（sqlite 数据库，.sqlite / .sqlite3 / .db）即可导入
- 导入成功后**无需联网**即可查询音标、释义与例句，查词速度最快
- 未导入离线词典时功能仍可用：查词走 **DeepSeek AI 释义兜底**（需联网）

> 💡 ECDICT 是开源英语词典数据库，可在其 GitHub 仓库获取 `ecdict.db`（约 46.8 万词条）。

## 生词本

- **收录生词**：在搜索框输入单词后添加；收录时自动查询音标与释义（离线词典优先，未命中走 AI）
- 词条卡片显示：单词 + 音标 + 释义摘要 + 状态与下次复习时间；支持**喇叭朗读**（已配置朗读时可用）
- 点击词条打开**详情**：完整释义、例句（中英对照）、**AI 精讲知识**（词根词缀拆解、同/反义词、固定搭配、其他变形，由 DeepSeek 生成并缓存）、SM-2 记忆参数与复习历史时间线
- 支持操作：编辑、手动设状态（学习中 / 已掌握 / 暂停）、删除（需二次确认）
- 顶部可按状态过滤（全部 / 学习中 / 已掌握 / 暂停），也可搜索

## 今日复习（SM-2 间隔重复）

按艾宾浩斯遗忘曲线动态规划每个词的复习间隔：

1. 显示卡片 → 先回忆，再点击卡片**翻转**看答案
2. 按掌握程度**四键自评**：`忘记` / `模糊` / `记得` / `轻松`
3. 后端按 **SM-2 算法**推进该词的间隔与熟练度
4. 「忘记」的词会回到队列尾部再测一次；标记为「已掌握」的词自动移出日常复习队列

复习页还可随时对每个词打开 AI 精讲、点喇叭朗读（词 / 例句）、手动调整状态。完成后展示本轮小结（各档次数）。

## 统计

「统计」页展示整体掌握情况与最近复习曲线：

- 总数（total）/ 学习中 / 已掌握 / 暂停 词数
- 今日到期（dueToday）/ 今日已复习 / 本周新增
- 近 7 天复习次数折线

## 语音朗读（TTS）

点击顶栏「朗读设置」配置**豆包语音合成（seed-tts）**：

1. 在豆包语音控制台「API Key 管理」创建 Key（UUID 格式，请求头 `X-Api-Key`）
2. 开通「豆包语音合成大模型」资源（`seed-tts-2.0`）
3. 填入 API Key、选择音色 → 点「试听」验证 → 保存（配置持久化在本地，跨窗口一致）

朗读按钮出现在**生词列表、收录框、复习卡、词条精讲**等处；未配置时按钮置灰。

## 跨窗口同步

- 主窗口入口角标、词典窗口内的复习数据通过 Tauri 事件（`vocab-due-updated`）实时同步——任意一侧收录 / 复习 / 删除，另一侧立即刷新
- 复习到期与统计均以本机时间计算，隔日打开会自然生成当天待复习队列

## 数据与存储

| 表 | 作用 |
|----|------|
| `vocab_words` | 词条：拼写、音标、释义 JSON、例句（含中文）、AI 精讲缓存、SM-2 参数（ease / factor / queue / interval / due 等）与状态 |
| `vocab_reviews` | 复习日志：时间、四键评分、复习间隔，用于详情时间线与统计曲线 |
