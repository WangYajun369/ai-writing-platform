# AI 助手

TimeWrite 内置 AI 写作助手，支持流式对话、RAG 上下文检索和 Agent 自动化写作辅助。

## 支持的服务商

| 服务商 | 默认端点 | 可选模型 | 说明 |
|--------|---------|---------|------|
| 智谱 BigModel | `https://open.bigmodel.cn/api/paas/v4` | `glm-5.1` | 默认服务商，国产大模型 |
| DeepSeek | `https://api.deepseek.com` | `deepseek-flash`、`deepseek-v4-pro` | 支持推理思考模式（Thinking） |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o` 等 | 需要 API Key |
| Ollama | `http://127.0.0.1:11434` | `qwen2.5:7b` 等 | 本地部署，无需 API Key |
| 自定义 OpenAI 兼容 | 任意 | 任意 | 支持任何 OpenAI 兼容 API |

> 上表默认值的单一真源在后端 `src-tauri/src/config/defaults.rs`（前端 `constants.ts` 仅维护可选模型列表）。**当前设置页对话服务商固定为 DeepSeek**，上表其余服务商为后端 OpenAI 兼容协议预留能力，选择控件暂未开放。

## 配置 AI 服务

在**设置 → AI 配置**页面完成配置。v0.4.0 起 AI 配置按模块拆分（对话配置；RAG 配置项仍在后端保留，但设置页入口已移除）：

### 对话配置（Chat Config）
1. **服务商**：当前固定为 DeepSeek（后续将扩展更多服务商）
2. **API 地址**：API 端点 URL（当前只读展示，随服务商确定）
3. **对话模型**：模型名称（如 `deepseek-flash`、`deepseek-v4-pro`）。点击「获取全部模型」可从服务商实时拉取最新列表并持久化，之后下拉即为服务端真实可选模型；未拉取时显示内置可选项。
4. **API Key**：各服务商独立管理（加密落库，密码形式展示）
5. **思考模式**：DeepSeek 推理模型可开启 Thinking，展示推理过程
6. **高级参数**：Temperature（0-1.0）、最大输出 Token（默认 131072）

### 语义检索（RAG）—— 设置页入口已移除

后端仍保留 RAG 相关命令与配置项（`rag_search` / `trigger_embedding` / `check_embedding_status` / `test_rag_connection`，默认 Embedding 模型 `embedding-3`），但**未接入对话**，因此设置页不再提供「语义检索」区块：

1. 向量索引不会自动生成，`embeddings` 表通常为空
2. AI 对话的上下文始终由 Agent 引擎内置工具（章节读取 / 世界观卡搜索）提供
3. 如未来接入语义检索，可恢复设置页入口或并入 Agent 工具

### API Key
对话 API Key 按服务商独立管理，以密码形式加密落库。

### 连接测试
配置完成后点击「测试连接」按钮：
- 🟢 **绿色**：连接成功，显示可用模型列表
- 🔴 **红色**：连接失败，显示错误详情
- 🔵 **蓝色动画**：检测中

## 使用 AI 对话

### 打开面板
点击编辑器工具栏的 🤖 按钮，在右侧打开 384px 宽的 AI 对话面板。

### 快捷提示词
消息为空时，点击快捷提示按钮：
- 帮我续写下一段
- 优化这段对话
- 推演剧情走向
- 分析人物性格

### 流式对话
- 输入消息后按回车或点击发送
- AI 回复**实时流式显示**，逐字呈现
- 支持 Markdown 渲染（表格、代码块、列表等）
- 对话历史按作品持久化保留

### 推理思考过程
使用 DeepSeek 或智谱推理模型时，AI 在正式回答前会先展示思考过程：
- **思考阶段**（thinking）：以可折叠区域展示推理过程
- **回答阶段**（answering）：流式输出正式回答
- **完成阶段**（done）：显示 Token/字数用量统计
- 点击展开/折叠可查看或隐藏完整的推理过程

### 上下文检索
AI 对话会自动检索当前作品的相关内容作为上下文：
1. Agent 引擎按需调用内置检索工具（章节读取 / 世界观卡搜索）获取相关资料
2. 检索结果作为工具结果注入推理过程
3. AI 回复时参考你的实际写作内容

> 检索基于 SQLite FTS5 全文搜索与 Agent 工具自主决策；向量索引（RAG）未接入对话，设置页入口已移除。

### 对话管理
- 对话按作品独立存储，切换作品时自动加载对应对话历史
- 支持清空当前作品所有对话记录
- 对话记录持久化到 localStorage，重启应用后恢复
- 请求详情面板：点击消息可查看完整的 System/User Prompt 请求内容

## Agent 自动化

AI 助手是**单轮对话**工具；如果需要 Agent 自主调用工具、多步推理完成复杂任务，请使用 [Agent 自动化面板](user-guide/agent-panel)。

Agent 已内置为 Rust 原生 ReAct 引擎（无需 Python 服务），提供 4 大技能：

| 技能 | 用途 | 使用模型 |
|------|------|---------|
| ✍️ 写作辅助 | 大纲生成、情节建议、角色对话模拟、冲突设计 | 当前对话模型 |
| 🔍 内容分析 | 文风分析、剧情连贯性、伏笔追踪、角色弧光 | 当前对话模型 |
| 📖 研究辅助 | 资料检索、世界观一致性校验、设定扩展 | 当前对话模型 |
| ✨ 润色优化 | 语法纠错、文笔润色、风格统一、冗余精简 | 当前对话模型 |

与 AI 助手的差异：

| 维度 | AI 助手（本页） | Agent 自动化 |
|------|----------------|-------------|
| 交互方式 | 多轮对话（v1.2 起由 Agent 引擎驱动） | 自主多步推理，自动调用工具 |
| 数据获取 | 上下文经引擎工具检索（RAG 后端预留） | 8 个数据库工具（6 通用 + 2 个拆书/笔记专用），按需读取章节/世界观 |
| 记忆 | 对话历史（滑动窗口压缩） | 三层记忆体，跨会话持久化 |
| 运行时 | 内嵌 Rust 主进程，无需外部服务 | 内嵌 Rust 主进程，无需外部服务 |

## 对话状态

| 状态 | 图标 | 说明 |
|------|------|------|
| 空闲 | ⭕ 灰色圆点 | 未进行连接测试 |
| 检测中 | 🔵 旋转动画 | 正在测试连接 |
| 已连接 | 🟢 对勾 | 连接正常 |
| 错误 | 🔴 警告 | 连接失败 |

## 技术说明

- 流式请求在 Rust 端通过 `reqwest` 处理，避免浏览器 CORS 问题
- 使用 Tauri 事件系统推送增量文本（`ai-stream-chunk` 事件）
- 支持 SSE（OpenAI 兼容）和 NDJSON（Ollama）两种流式协议
- 非 Ollama 服务商需要 API Key 认证
- AI 配置通过 localStorage 持久化保存，自动兼容旧版格式迁移
