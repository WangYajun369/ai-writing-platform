# 书库管理

> **适用版本**：`1.7.0`　|　**最后核对**：2026-09-05

书库是 TimeWrite 的首页，用于管理所有写作作品。

## 功能概览

- 多作品**网格视图**（封面卡片式布局），虚拟化滚动，作品再多也不卡顿
- 搜索、排序（更新时间 / 创建时间 / 书名 / 字数）
- 创建/删除作品，书籍封面设置
- 首页右上角插件入口：任务卡（今日应办数角标）、英语字典（今日待复习数角标）

> v1.0.1 起已移除列表视图，仅保留网格模式。

## 搜索与排序

### 搜索
在顶部搜索框输入关键字，实时过滤作品列表。

### 排序
支持四种排序方式：
- **按更新时间**（默认）：最近编辑的排在前面
- **按创建时间**：最新创建的排在前面
- **按字数**：字数最多的排在前面
- **按书名**：字母/拼音顺序排列

## 创建作品

1. 点击「新建作品」按钮
2. 输入书名（必填）、作者、简介
3. 可选：设置封面图片、每日目标字数
4. 点击「开始创作」完成创建

## 编辑作品信息

在书库页面可编辑已创建的作品信息：
1. 点击作品卡片进入编辑模式
2. 可修改：书名、作者、简介、封面图片、每日目标字数
3. 保存后自动更新

## 封面设置

支持为作品设置自定义封面：

1. 在作品卡片上点击封面区域
2. 选择本地图片文件
3. 支持的格式：JPG、PNG、WebP
4. 封面图片会自动复制到应用数据目录

## 写作进度

### 每日目标
- 在书库中可设置每日写作字数目标
- 进度以环形图可视化展示
- 帮助追踪写作习惯和进度

### 字数统计
每个作品卡片显示当前总字数，实时更新。

## 删除与回收站

- 右键点击作品卡片，选择「删除」
- 作品及其所有章节、卷、世界观卡片将被**软删除**
- 可通过回收站（TrashModal）查看、恢复或彻底删除已删除的内容
- 软删除的作品保留 `deleted_at` 时间戳，数据不会立即丢失
- 彻底删除不可撤销
