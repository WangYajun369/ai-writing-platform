# Agent 自动化

> **适用版本**：`1.0.0`　|　**最后核对**：2026-08-31

Agent 是 TimeWrite 的**自主写作助理**。与 AI 助手的「一问一答」不同，Agent 会自己规划步骤、调用工具读取你的章节和世界观设定，完成多步推理任务，并拥有跨会话的长期记忆。

---

## 与 AI 助手的区别

| 维度 | [AI 助手](user-guide/ai-assistant) | Agent 自动化（本页） |
|------|------------------|----------------|
| 交互方式 | 单轮/多轮对话 | 自主多步推理，自动调用工具 |
| 数据获取 | RAG 检索片段 | 6 个数据库工具，按需读取章节/世界观 |
| 记忆 | 对话历史（滑动窗口压缩） | 三层记忆体，跨会话持久化 |
| 需要 Python | 否 | 是（需启动 Agent 服务） |
| 适合场景 | 快速提问、局部润色、灵感激发 | 大纲生成、全文一致性检查、复杂分析 |

---

## 1. 启动 Agent 服务

Agent 面板顶部显示服务状态：

| 状态 | 徽章 | 说明 |
|------|------|------|
| `stopped` | 未启动 | 需手动点击「启动」 |
| `starting` | 启动中... | 正在拉起 Python 子进程 |
| `running` | 已连接 | 可以开始使用 |
| `crashed` | 异常 | 看门狗会自动重启（最多 3 次），也可手动重启 |

点击右上角「**启动**」按钮即可。若反复失败，见 [故障排查](#7-故障排查)。

> Agent 由 Rust 侧自动管理，`src-tauri/src/python/manager.rs` 会探测 Python 解释器（优先 `agent/.venv`）、清理端口僵尸进程，并每 10 秒健康检查，崩溃自动重启。

## 2. 四大技能

面板顶部为技能选择器，点击即可切换：

### ✍️ 写作辅助 `writing`

**能力**：大纲生成、情节建议、角色对话模拟、冲突设计

**快捷指令**：

- 为当前章节生成下一章的详细大纲
- 分析主角的性格，设计一个合理的冲突情节
- 基于已有世界观，提供 3 个情节发展方向

**会自动查阅**：章节摘要、章节分页内容、章节列表、世界观卡片、整书上下文

**使用模型**：云端 DeepSeek（需 API Key）

---

### 🔍 内容分析 `analysis`

**能力**：文风分析、剧情连贯性检查、伏笔追踪、角色弧光、节奏评估

**快捷指令**：

- 分析最近 5 章的叙事节奏
- 检查当前章节与前面章节的伏笔关联
- 评估主要角色的性格一致性

**输出特点**：会用 ✅ / ⚠️ / ❌ 标注问题严重程度，并用代码块引用原文段落

**使用模型**：云端 DeepSeek（需 API Key）

---

### 📖 研究辅助 `research`

**能力**：背景资料检索、世界观一致性校验、设定扩展、关系图谱

**快捷指令**：

- 检索当前书籍的所有世界观设定
- 检查新章节内容是否与已有设定冲突
- 根据已有设定，扩展魔法体系的细节

**输出特点**：用表格对比「已有设定 vs 新增设定」，标记冲突点

**使用模型**：云端 DeepSeek（需 API Key）

---

### ✨ 润色优化 `polish`

**能力**：语法纠错、文笔润色、风格统一、冗余精简

**快捷指令**：

- 润色当前章节，保持原文风格
- 检查并修正语法和标点错误
- 优化当前章节的句式结构，增强可读性

**输出特点**：分「润色后文本」和「改动说明」两部分，用 ~~删除线~~ 标注删除、**加粗**标注新增

**使用模型**：**本地 Ollama**（无需联网，需本地已拉取 `qwen2.5:7b`）

> 润色属于简单任务，走本地模型以节省成本；写作/分析/研究属复杂推理，走云端 DeepSeek。

## 3. 基本使用流程

1. 打开编辑器右侧的 **Agent 面板**（若未显示，在工具栏点击 Agent 图标）
2. 点击「**启动**」，等待状态变为「已连接」
3. 在顶部选择要使用的**技能**
4. 在输入框输入指令（或点击欢迎页的快捷指令自动填充）
5. 按 `Enter` 发送（`Shift+Enter` 换行）
6. 观察流式输出 —— Agent 会显示工具调用过程与最终结果
7. 生成过程中可点击「**停止生成**」中断

**输入框快捷键**

| 按键 | 行为 |
|------|------|
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |

## 4. 记忆管理

点击面板右上角「**记忆**」按钮进入记忆管理界面。

Agent 会在每次对话后**自动提取**并保存关键信息，下次对话时自动注入相关记忆，无需重复说明背景。

### 三种记忆类型

| 类型 | 图标 | 含义 | 示例 |
|------|------|------|------|
| 用户偏好 `preference` | 🔵 | 你的风格、语气、格式偏好 | 「主角对话要带方言色彩」 |
| 历史决策 `decision` | 🟠 | 曾做出的设定决策 | 「修仙体系定为练气→筑基→金丹」 |
| 经验教训 `lesson` | 🟢 | 什么有效、什么无效 | 「第三章的倒叙手法读者反馈不佳」 |

### 记忆操作

- **查看**：按作品隔离，列出全部记忆条目及其关键词、相关度
- **编辑**：修改内容、关键词或类型
- **删除**：删除单条记忆
- **清空**：清空当前作品的全部记忆

### 检索机制

记忆按以下策略排序后注入对话：

```
相关性分 = 基础分 × 关键词交集加成 × 类型权重(偏好1.2 / 决策1.0 / 经验0.8) × 时间衰减
```

注入总量受 Token 预算约束（默认 600 tokens），优先注入最相关的内容。

> 记忆存储在 `agent/data/agent_memory.db`（SQLite），按作品隔离，持久保存。

## 5. 模型路由说明

| 技能 | 模型 | 位置 | 成本 |
|------|------|------|------|
| 润色优化 | Ollama `qwen2.5:7b` | 本地 `127.0.0.1:11434` | 免费 |
| 写作辅助 | DeepSeek | 云端 `https://api.deepseek.com` | 需 API Key |
| 内容分析 | DeepSeek | 云端 | 需 API Key |
| 研究辅助 | DeepSeek | 云端 | 需 API Key |

**配置方式**：云端模型使用你在「设置 → AI 配置 → 对话配置」中填写的 API Key 与端点。Agent 会优先使用请求级配置，缺失时才回退到 `agent/config.py` 的全局默认值（可通过环境变量覆盖）。

**DeepSeek 思考模式**：Agent 场景默认启用 `thinking` 且 `reasoning_effort = max`，以获得更强的工具调用推理能力。

## 6. 数据安全

**Agent 不会修改你的章节内容。**

Python Agent 不直接访问数据库，只能通过 Rust Bridge（端口 9876）**读取**数据。所有写操作（保存、快照恢复等）的唯一入口始终在 Rust 侧。Agent 的输出以文本形式展示，是否采纳由你决定。

## 7. 故障排查

### 状态一直显示「未启动」或反复「异常」

| 原因 | 解决办法 |
|------|---------|
| 未初始化 Python 环境 | 执行 `pnpm agent:setup` 创建 `agent/.venv` 并安装依赖 |
| `uvicorn` 不可用 | AgentManager 会验证解释器可用性；执行 `pnpm agent:check` 诊断 |
| 端口 9877 被占用 | 启动时会自动清理僵尸进程；仍失败可手动 `lsof -i :9877` 查杀 |
| 打包版找不到 `agent/` | 确认 `tauri.conf.json` 的 `resources` 包含 `../agent/` |

### 提示「无法连接到本地数据桥接服务」

Bridge（端口 9876）未就绪。Agent 会自动重试 3 次（0.5s → 1s → 2s 退避），若仍失败：

1. 确认应用正常启动（Bridge 随 Rust 主进程启动）
2. 重启应用
3. 在调试控制台查看 Bridge 相关日志

### 润色技能无响应

润色走**本地 Ollama**，确认：

- Ollama 已启动并监听 `http://127.0.0.1:11434`
- 已拉取模型：`ollama pull qwen2.5:7b`

### 「停止生成」后仍在消耗 Token

当前 `/skills/cancel` 为占位实现，无法真正中断 Python 侧的任务。这是已知问题（见 [优化报告](meta/optimization-report) 问题 28），建议等待任务完成或重启 Agent 服务。

### 查看详细日志

设置环境变量 `AGENT_TRACE_LEVEL=DEBUG` 可输出每次 HTTP 请求、工具调用、记忆检索与缓存命中的详细信息，日志会出现在调试控制台。
