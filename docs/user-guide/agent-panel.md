# Agent 自动化

> **适用版本**：`1.2.0`　|　**最后核对**：2026-09-02

Agent 是 TimeWrite 的**自主写作助理**。与 AI 助手的「一问一答」不同，Agent 会自己规划步骤、调用工具读取你的章节和世界观设定，完成多步推理任务，并拥有跨会话的长期记忆。

---

## 与 AI 助手的区别

| 维度 | [AI 助手](user-guide/ai-assistant) | Agent 自动化（本页） |
|------|------------------|----------------|
| 交互方式 | 多轮对话（v1.2 起由 Agent 引擎驱动） | 自主多步推理，自动调用工具 |
| 数据获取 | 上下文经引擎工具检索（RAG 后端预留） | 6 个数据库工具，按需读取章节/世界观 |
| 记忆 | 对话历史（滑动窗口压缩） | 三层记忆体，跨会话持久化 |
| 运行时 | 内嵌 Rust 主进程，无需外部服务 | 内嵌 Rust 主进程，无需外部服务 |
| 适合场景 | 快速提问、局部润色、灵感激发 | 大纲生成、全文一致性检查、复杂分析 |

---

## 1. 引擎状态

Agent 引擎随应用启动**内嵌运行**于 Rust 主进程（v1.1 起），无需手动启动：

| 状态 | 说明 |
|------|------|
| `running` | 恒为运行中（引擎内嵌 Rust，无外部进程可启停） |

> v1.1 起不再需要 Python 环境，也没有「启动 Agent」按钮：
> 原 Python 子进程管理（解释器探测、端口清理、看门狗重启）已随迁移移除。
> 若遇响应问题，见 [故障排查](#7-故障排查)。

## 2. 四大技能

面板顶部为技能选择器，点击即可切换：

### ✍️ 写作辅助 `writing`

**能力**：大纲生成、情节建议、角色对话模拟、冲突设计

**快捷指令**：

- 为当前章节生成下一章的详细大纲
- 分析主角的性格，设计一个合理的冲突情节
- 基于已有世界观，提供 3 个情节发展方向

**会自动查阅**：章节摘要、章节分页内容、章节列表、世界观卡片、整书上下文

**使用模型**：云端 DeepSeek（需 API Key）

---

### 🔍 内容分析 `analysis`

**能力**：文风分析、剧情连贯性检查、伏笔追踪、角色弧光、节奏评估

**快捷指令**：

- 分析最近 5 章的叙事节奏
- 检查当前章节与前面章节的伏笔关联
- 评估主要角色的性格一致性

**输出特点**：会用 ✅ / ⚠️ / ❌ 标注问题严重程度，并用代码块引用原文段落

**使用模型**：云端 DeepSeek（需 API Key）

---

### 📖 研究辅助 `research`

**能力**：背景资料检索、世界观一致性校验、设定扩展、关系图谱

**快捷指令**：

- 检索当前书籍的所有世界观设定
- 检查新章节内容是否与已有设定冲突
- 根据已有设定，扩展魔法体系的细节

**输出特点**：用表格对比「已有设定 vs 新增设定」，标记冲突点

**使用模型**：云端 DeepSeek（需 API Key）

---

### ✨ 润色优化 `polish`

**能力**：语法纠错、文笔润色、风格统一、冗余精简

**快捷指令**：

- 润色当前章节，保持原文风格
- 检查并修正语法和标点错误
- 优化当前章节的句式结构，增强可读性

**输出特点**：分「润色后文本」和「改动说明」两部分，用 ~~删除线~~ 标注删除、**加粗**标注新增

**使用模型**：**本地 Ollama**（无需联网，需本地已拉取 `qwen2.5:7b`）

> 润色属于简单任务，走本地模型以节省成本；写作/分析/研究属复杂推理，走云端 DeepSeek。

## 3. 基本使用流程

1. 打开编辑器右侧的 **Agent 面板**（若未显示，在工具栏点击 Agent 图标）
2. 在顶部选择要使用的**技能**
3. 在输入框输入指令（或点击欢迎页的快捷指令自动填充）
4. 按 `Enter` 发送（`Shift+Enter` 换行）
5. 观察流式输出 —— Agent 会显示工具调用过程与最终结果
6. 生成过程中可点击「**停止生成**」中断

**输入框快捷键**

| 按键 | 行为 |
|------|------|
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |

## 4. 记忆管理

点击面板右上角「**记忆**」按钮进入记忆管理界面。

Agent 会在每次对话后**自动提取**并保存关键信息，下次对话时自动注入相关记忆，无需重复说明背景。

### 三种记忆类型

| 类型 | 图标 | 含义 | 示例 |
|------|------|------|------|
| 用户偏好 `preference` | 🔵 | 你的风格、语气、格式偏好 | 「主角对话要带方言色彩」 |
| 历史决策 `decision` | 🟠 | 曾做出的设定决策 | 「修仙体系定为练气→筑基→金丹」 |
| 经验教训 `lesson` | 🟢 | 什么有效、什么无效 | 「第三章的倒叙手法读者反馈不佳」 |

### 记忆操作

- **查看**：按作品隔离，列出全部记忆条目及其关键词、相关度
- **编辑**：修改内容、关键词或类型
- **删除**：删除单条记忆
- **清空**：清空当前作品的全部记忆

### 检索机制

记忆按以下策略排序后注入对话：

```
相关性分 = 基础分 × 关键词交集加成 × 类型权重(偏好1.2 / 决策1.0 / 经验0.8) × 时间衰减
```

注入总量受 Token 预算约束（默认 600 tokens），优先注入最相关的内容。

> 记忆存储在应用数据目录 `time_write.db` 的 `memories` 表中，按作品隔离，持久保存。

## 5. 模型路由说明

| 技能 | 模型 | 位置 |
|------|------|------|
| 写作辅助 / 内容分析 / 研究辅助 / 润色优化 | 当前对话模型 | 设置 → AI 配置 |

**配置方式**：全部技能统一使用「设置 → AI 配置 → 对话配置」中填写的 API Key 与端点（智谱 / DeepSeek / OpenAI 兼容），引擎按对话配置路由，无本地模型依赖。

**推理模式**：Agent 场景默认启用思考且 `reasoning_effort = max`，以获得更强的工具调用推理能力。

## 6. 数据安全

**Agent 不会修改你的章节内容。**

Agent 引擎无法修改章节内容：它只能通过内置只读工具读取章节与世界观资料，所有写操作（保存、快照恢复等）的唯一入口始终在 Rust 命令层。Agent 的输出以文本形式展示，是否采纳由你决定。

## 7. 故障排查

### Agent 无响应 / 报错

| 原因 | 解决办法 |
|------|---------|
| 模型 API Key 无效或欠费 | 在「设置 → AI 配置」检查/更新 API Key，并用「测试连接」验证 |
| 网络不可达 | 确认可访问对话模型 API 端点 |
| 长任务无输出 | 引擎内置 60s 断流保护会自动结束超时任务；取消后重试即可 |
| 任务中途中断 | 可继续提问，引擎会在下一轮正常响应 |

### 「停止生成」后仍在消耗 Token

点击停止后引擎收到全局取消标志时即中断；若增量已在返回途中会补全显示，不会额外发起新请求。

### 查看详细日志

在调试窗口（菜单 → 调试工具）查看 Rust 后端与应用日志；点击消息气泡可打开详情面板查看完整的 System/User Prompt。
