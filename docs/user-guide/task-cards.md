# 任务卡 · 项目管理

> **适用版本**：`1.6.0`　|　**最后核对**：2026-09-05

TimeWrite 内置「任务卡 · 项目管理」模块（v1.5.0 新增）：以**项目**为中心管理日常任务，支持三态看板（待办 / 进行中 / 完成）、计划今日、截止与逾期提醒、标签 / 子任务 / 附件 / 模板 / 重复任务等能力。它同时**取代了 v1.4.0 及之前的「个人日程」**，首页日记面板的日历状态点与「当日任务」均由任务卡数据驱动。数据全部保存在本机 `time_write.db`（SQLite），离线可用。

## 入口

- 书库首页右上角「**任务卡**」按钮（带剪贴板图标）→ 打开 / 切换任务卡独立窗口；按钮上的角标显示**今日应办数**（今日到期 + 计划今日 + 逾期的未完成数），随任务变化实时刷新
- 全局命令面板（主窗口 `Ctrl/Cmd + Shift + P`）搜索「任务卡」，可**打开窗口** / **直达今日视图** / **直达全部任务**
- 首页日记面板「当日任务」区的「打开任务卡」链接

## 窗口布局

任务卡独立窗口（暗色卡片风格）分为：

| 区域 | 说明 |
|------|------|
| 左侧导航 | 今日 / 项目 / 回收站；底部「标签与设置」打开设置抽屉；窗口右上角铃铛为提醒中心 |
| 今日视图 | 当日应办事项总览，按状态分区的任务卡片列表 |
| 项目视图 | 项目卡片列表（全部 / 进行中 / 已完成 / 已归档），点击进入项目详情 |
| 回收站 | 已删除的项目与任务（软删除），可恢复或彻底删除 |
| 设置抽屉 | 标签管理 / 任务模板 / 日程迁移 / 提醒偏好 |

> 打开任务卡窗口后，命令面板深链 `section=today|all` 可直达今日 / 全部任务视图。

## 项目（Project）

项目是任务的容器，新建项目时填写：**名称**、emoji 图标、颜色、描述、计划开始 / 结束日期；创建后可：

- **置顶**（Pin），在项目列表中优先展示
- 进入详情页切换 **看板 / 列表** 双视图，按项目执行任务管理
- 右键 / 菜单完成、归档或删除项目（删除进回收站）

项目卡片会展示实时统计（总数 / 待办 / 进行中 / 已完成 / 逾期）。

## 任务（Task Card）

在项目内新建任务，或在「今日」页快速添加，字段包括：

| 字段 | 说明 |
|------|------|
| 标题 / 描述 | 富文本描述支持加粗、列表、图片等（描述带 `mark` 命中高亮搜索） |
| 优先级 | 高 / 中 / 低，用于排序与筛选 |
| 截止时间 / 计划开始 | 决定任务落在哪一天的日历状态点 |
| 计划今日 | 勾选后任务在今日视图中单独分组，跨日自动顺延清理 |
| 标签 | 可多选，颜色区分 |
| 子任务 | 清单式拆分，勾选完成，父任务进度联动 |
| 附件 | 本地文件（记录文件名 / 类型 / 大小），可一键打开（P2） |
| 重复 | 每天 / 每周（指定周几）/ 每月 / 每 N 间隔，可设结束日期（P2） |
| 任务级提醒 | 跟随全局或单独指定（截止前一天 / 当天 / 逾期 / 自定义时间） |
| 备注 / 富文本备注 | 个人备忘，也可在套用模板时预填 |

### 看板操作

- 看板为**待办 / 进行中 / 完成**三列；跨列**拖拽**改变状态，同列拖拽手动排序（手动排序模式下）
- 逾期任务带红色角标强调
- 完成任务会弹出**完成总结**编辑器（TipTap 富文本，可跳过）；「重新打开」恢复待办并保留既有总结

### 今日视图

今日页按分区展示：**逾期（红）** → **进行中（高优先级）** → **今日截止** → **计划今日** → **今日已完成（折叠）**，顶部提供今日完成率进度条与快速添加框；卡片行尾可「**顺延到明天**」（保留原时刻，无截止则设为明早 09:00）。

### 全部任务视图

全局**搜索 / 筛选 / 排序**的扁平列表：关键词命中标题 / 备注 / 描述 / 标签 / 项目名（命中词高亮）；按状态、标签、优先级、截止范围（逾期 / 今天 / 本周 / 本月）筛选；按截止 / 优先级 / 创建 / 更新时间排序。

### 详情与时间线

任务详情内折叠展示**操作记录时间线**（创建 / 完成 / 重新打开 / 更新 / 子任务 / 附件等，最新在前）；项目详情可查看近 8 周「新增 / 完成」**周报双柱图**与项目动态。

## 设置抽屉

打开方式：任务卡窗口左侧导航底部「标签与设置」按钮。

| 页签 | 能力 |
|------|------|
| 标签管理 | 新建 / 改名 / 换色 / 启用停用 / 删除标签（删除会同时解除任务关联） |
| 任务模板 | 预设标题 / 描述 / 优先级 / 备注 / 标签 / 子任务清单 / 截止偏移，一键套用创建任务 |
| 日程迁移 | 把旧「个人日程」（`schedules` 表）**一键迁移**为项目「日程迁移」下的任务（幂等，已完成状态保留） |
| 提醒偏好 | 到期 / 逾期提醒开关与时间（截止前一天 / 当天 / 逾期每日，默认 09:00 一次），支持每日待办提醒，可「立即检查」手动发送 |

提醒依赖系统通知能力（`tauri-plugin-notification`），首次使用请允许应用发送通知；任务卡窗口内右上角**铃铛**为站内提醒中心（含未读角标，可点击直达任务）。

## 与日记模块联动

- 首页日历的**日期下方状态点**由任务卡数据驱动：逾期红 / 今日绿 / 未来蓝 / 已完成灰
- 首页「当日任务」区展示选中日期截止的任务，支持快速勾选完成 / 重新打开，完整操作跳转任务卡窗口
- 任何任务变更（含任务卡窗口内操作）都会广播 `tasks-data-updated`，首页角标与日历即时刷新

## 数据与存储

- 数据表：`projects`、`tasks`、`tags`、`task_tags`、`task_meta`（铃铛已读 / 提醒偏好等）、`task_subtasks`、`attachments`、`task_activity_logs`（操作日志）、`task_templates`、`project_milestones`（里程碑，为规划预留）
- 项目与任务均**软删除**（`deleted_at`），回收站可恢复 / 彻底删除；任务还支持过期回收站自动清理
- 与书库 / 章节 / 世界观 / 日记等同库存储于本机 `time_write.db`
