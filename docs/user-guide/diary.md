# 日记与个人日程

TimeWrite 内置「日记与个人日程」模块，入口在书库首页右侧栏，数据保存在本机 `time_write.db`（SQLite）中，离线可用。界面自上而下分为三个区块：**按月日历**、**当日日记**、**当日个人日程**，点击不同日期，后两块内容会随之联动切换。

## 按月日历与状态点

- 点击顶部「‹」「›」切换月份，「今天」一键回到当前月
- **日期上方实心圆点**：该日已写日记
- **日期下方小圆点**：该日日程状态

| 圆点颜色 | 含义 |
|----------|------|
| 红 | 日期已过去但仍存在未完成日程（逾期） |
| 绿 | 今天 |
| 蓝 | 未来日期有日程 |
| 灰 | 当日日程已全部完成 |

点击某个日期后，下方「日记」与「个人日程管理」两块会切换为这一天的内容。

## 写 / 编辑日记

- 选中某一天后：
  - 没有日记 → 点击卡片上的「写这一天的日记」
  - 已有日记 → 点击卡片「编辑日记」
- 面板顶部的铅笔图标 → 快速写 / 编辑**今天**的日记
- 编辑器为 TipTap 富文本，支持 H1–H3 标题、加粗 / 斜体 / 删除线、文字颜色、任务列表、表格（合并 / 拆分单元格）、代码块（语法高亮）、图片插入（本地图片自动编码压缩，可裁剪）等
- 编辑器底部实时显示**字数**，并给出**高频关键字**预览（保存后展示在日记卡片上）

### 保存与删除规则

| 操作 | 行为 |
|------|------|
| 输入停顿 | 约 300ms 防抖后自动保存 |
| `Ctrl/Cmd + S` | 立即保存 |
| 点「×」、按 `Esc` 或点击遮罩 | 先落盘再关闭（组件卸载另有兜底保存） |
| 内容与已存一致 | 不重复写库 |
| 内容被清空 | 自动删除该日日记记录 |
| 删除按钮 | 需二次确认：点击后按钮进入确认态，2.5 秒内再次点击才真正删除，超时自动恢复 |

保存成功后，日历上的日记圆点会立刻出现，日记卡片同步刷新。

## 「看日记」——书页式浏览

面板右上角「看日记」按钮打开书页式浏览窗口，**仅展示、不提供编辑**：

- 弹窗像翻开一本书：一次展开**左右两页**，左侧较早日、右侧较晚日（左旧右新），中间有书脊
- 只有写过日记的日子才会占一页，自动跳过没有日记的日期
- 打开即定位到**最近写的两篇**；若总篇数为奇数，最后一篇单独显示在右页（左页为装饰封面）
- 翻页方式：点击左右两侧大按钮、顶栏「‹」「›」，或键盘 `←` / `→`（方向键同时翻左右两页，向更早或更晚移动）
- 每页展示：完整日期标题（当天带「今天」标记）、关键字标签、正文（含图片、表格等原排版）、字数、更新时间
- 顶栏显示当前页码（「第 x / y 页 · 共 n 篇」）
- 关闭：`Esc`、右上角「×」或点击弹窗背景

## 当日个人日程

- **添加**：在输入框输入内容后回车（或点击「添加」）
- **完成**：勾选条目左侧复选框，日历对应日期的圆点会变为已完成灰点
- **编辑**：双击条目进入编辑，回车保存、`Esc` 取消
- **删除**：鼠标悬停条目时出现删除按钮
- 面板标题右侧显示完成进度（例如 2/3）

## 数据与存储

- 每天最多一篇日记：`diaries` 表，`diary_date` 唯一（存储富文本 HTML、字数、关键字、创建 / 更新时间）
- 每天可有多条日程：`schedules` 表（`schedule_date` 日期 + `done` 完成标记）
- 与书库 / 章节 / 世界观等数据同库存储于本机 `time_write.db`，随应用启动自动建表与索引
