# 功能特性

TimeWrite（智写时光）为小说作者提供完整的写作工作流。

## 书库管理
- ✅ 多作品管理，网格/列表双视图切换
- ✅ 虚拟化滚动，流畅处理大量作品
- ✅ 搜索、排序（时间/字数/书名）
- ✅ 创建/编辑/删除作品，回收站管理（软删除可恢复）
- ✅ 书籍封面设置（JPG/PNG/WebP）
- ✅ 作品信息编辑（书名/作者/简介/封面/每日目标）
- ✅ 每日写作目标 + 进度环可视化

## 日记与任务（个人日程）
- ✅ 首页右侧「日记」面板：按月日历 + 当日日记卡片 + 当日任务（任务卡数据驱动，v1.5.0）
- ✅ 日历状态点：已写日记圆点（日期上方）/ 任务状态点（下方：逾期红 / 今天绿 / 未来蓝 / 已完成灰）+ 图例
- ✅ 日记富文本编辑器（TipTap）：标题、颜色、表格（合并/拆分单元格）、图片（可裁剪）、代码块、任务清单
- ✅ 实时字数统计 + 高频关键字自动提取（正文与卡片预览展示）
- ✅ 自动保存（300ms 防抖），Esc / Ctrl+S 立即保存，关闭前兜底落盘
- ✅ 内容清空自动删除该日记录；删除需二次确认（误触自动复原）
- ✅ 「看日记」**独立窗口**书页式浏览（v1.5.0 由弹窗升级）：按月分章、左右对页翻书（左旧右新）、跳过无日记日期；打开定位**本月第一篇**（本月无则落到最近有日记月份），顶栏**年月下拉**跨月直跳；留白处为装饰「扉页」（圆环羽毛笔 + 年月大字，左「新的一月」/ 右「本月终章」）；箭头 / 方向键整组翻页、仅展示只读
- ✅ 当日任务：勾选快速完成 / 重新打开（可填完成总结），完整操作跳转任务卡窗口
- ✅ 旧「个人日程」一键迁移为任务卡项目（`schedules` 表保留，任务卡窗口「设置 → 日程迁移」）
- ✅ 本地 SQLite 存储：`diaries`（每天至多一篇，`diary_date` 唯一）+ 任务卡相关表

> 使用说明见 [日记与任务](user-guide/diary)。

## 任务卡 · 项目管理（v1.5.0）
- ✅ home-header 内置插件：书库首页「任务卡」入口 + 今日应办数角标；命令面板可打开 / 直达今日 / 直达全部
- ✅ **项目**：名称 / emoji 图标 / 颜色 / 计划起止日期，置顶、完成、归档、回收站；卡片实时统计
- ✅ **看板 / 列表双视图**：待办 / 进行中 / 完成三列 + 跨列拖拽（@dnd-kit）+ 手动排序；列表批量勾选；关键词 / 优先级 / 标签 / 截止筛选
- ✅ **任务**：富文本描述、优先级、计划开始 / 截止、计划今日、标签、子任务、附件（打开本地文件）、重复规则、任务级提醒、完成总结
- ✅ **今日视图**：逾期 / 进行中 / 今日截止 / 计划今日 / 已完成分区 + 完成率进度条 + 「顺延到明天」；「计划今日」跨日自动滚动清理
- ✅ **全部任务视图**：全局搜索（命中高亮）+ 状态 / 标签 / 优先级 / 截止范围筛选 + 排序
- ✅ 标签管理、任务模板、操作日志时间线、项目周报（近 8 周新增/完成柱图）
- ✅ 到期 / 逾期系统通知提醒 + 窗口内铃铛中心（未读角标）
- ✅ 软删除回收站（项目与任务），过期回收站自动清理
- ✅ 本地 SQLite 存储：`projects` / `tasks` / `tags` / `task_tags` / `task_meta` / `task_subtasks` / `attachments` / `task_activity_logs` / `task_templates` 等 10 张新表

> 使用说明见 [任务卡 · 项目管理](user-guide/task-cards)。

## 英语字典·生词本（v1.4.0）
- ✅ home-header 内置插件：书库首页「英语字典」玫红入口 + 今日待复习数角标
- ✅ 独立悬浮窗口：生词本 / 今日复习 / 统计三页签，跨窗口事件实时同步
- ✅ 生词收录：自动查音标与释义（**ECDICT 离线词库**优先，**DeepSeek AI 释义**兜底）
- ✅ **SM-2 间隔重复复习**：闪卡翻转 + 四键自评（忘记 / 模糊 / 记得 / 轻松），艾宾浩斯遗忘曲线自动排程
- ✅ **AI 精讲**：词根词缀拆解、同反义词、固定搭配、词形变化（DeepSeek 生成并缓存）
- ✅ **TTS 语音朗读**：豆包语音合成（seed-tts-2.0），单词与例句一键朗读
- ✅ 复习日志与统计曲线（`vocab_words` / `vocab_reviews` 表）

> 使用说明见 [英语字典·生词本](user-guide/vocabulary)。

## Agent 自动化（Rust 原生引擎）

> v1.0.0 引入、v1.1 起迁移为 **Rust 原生引擎**，无需 Python 环境。

- ✅ **4 大写作技能**：写作辅助 / 内容分析 / 研究辅助 / 润色优化
- ✅ **自主多步推理**：Rust ReAct 循环（SSE 流式），自动规划并调用工具（≤15 轮）
- ✅ **6 个数据库工具**：读取章节/摘要/分页、列出章节、搜索世界观、整书上下文
- ✅ **模型配置化**：默认云端 DeepSeek，可配置 OpenAI 兼容端点（含 Ollama 等）
- ✅ **三层记忆体**：偏好 / 决策 / 经验，`memories` 表并入主库（v1.1），跨会话自动注入
- ✅ **记忆管理界面**：查看、编辑、删除、清空
- ✅ **动态 Prompt**：核心提示词 + 关键词匹配的场景提示（≤3 条），KV Cache 友好
- ✅ **任务取消**：Rust 全局取消标志，可实时中断引擎循环（原 `/skills/cancel` 占位问题已解决）
- ✅ **旧记忆自动迁移**：Python 期 `agent_memory.db` 启动时幂等导入主库
- ✅ **SSE 流式输出**：前端 RAF 缓冲合并，避免高频重渲染
- ✅ **数据主权**：工具经 repository 层直查 SQLite，写操作唯一入口仍在 Rust

> 详见 [Agent 自动化](user-guide/agent-panel) 与 [Agent 引擎架构](architecture/agent-architecture)。
