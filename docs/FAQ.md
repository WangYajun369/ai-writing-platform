# 常见问题

> **适用版本**：`1.7.0`　|　**最后核对**：2026-09-05

## 使用相关

### Q: TimeWrite 支持哪些平台？
支持 **macOS**（Apple Silicon / Intel）、**Windows**（NSIS 安装包）与 **Linux**（deb / AppImage，v1.6.0 起提供构建目标）。

### Q: 数据存储在哪里？
数据存储在应用本地数据目录的 SQLite 数据库中。macOS 通常在 `~/Library/Application Support/com.ukcoder.timewrite/`。

### Q: 如何备份数据？
两种方式结合使用最稳妥：

1. **加密备份（推荐）**：导出 `.tw` 全量或单作品备份（AES-256-GCM 加密），可完整恢复书库、章节、世界观与快照；
2. **格式导出**：导出为 TXT / Markdown / HTML，适合发布或外部阅读。

建议定期做一次全量加密备份。v1.7.0 起导入备份前会先显示预览与逐表对账，重复导入同一文件也能自动识别。详见 [导入导出](user-guide/import-export)。

### Q: 导入备份时提示「校验失败」或「版本过高」怎么办？
- `E_BACKUP_VERSION`：备份来自更高主版本，需先升级 TimeWrite（提示中附「前往更新」按钮）；
- 指纹校验失败：文件在传输或存储中被改动，为保护数据会**拒绝导入且不写入任何内容**，请改用原始备份文件；
- `E_IO_BUSY`：已有导入/导出任务在进行，等它结束再试。

### Q: 专注模式下如何恢复面板？
按 `Esc` 键退出专注模式，所有面板恢复之前状态。

### Q: AI 助手支持哪些模型？
默认集成智谱 BigModel（`glm-5.1`）和 DeepSeek（支持推理思考模式），同时支持任何 OpenAI 兼容 API。

### Q: 为什么 AI 回复被截断？
检查设置中的「最大输出 Token」参数，确保设置足够大的值（默认 131072）。

### Q: 如何设置写作目标？
在书库页面，作品卡片上点击目标设置区域，输入每日目标字数。进度以环形图显示。

### Q: 章节删除后能恢复吗？
章节使用软删除机制（`deleted_at` 字段），可通过回收站（TrashModal）查看、恢复或彻底删除已删除的章节、卷和作品。

### Q: v1.4.0 的「个人日程」数据还在吗？如何迁移到任务卡？
保留。v1.5.0 起旧「个人日程」由「任务卡 · 项目管理」取代（日历与首页的当日任务均改为任务卡数据驱动），旧数据仍在 `schedules` 表中。打开任务卡窗口 → 左侧导航底部「标签与设置」→「日程迁移」页签，可一键把历史日程迁移为项目「日程迁移」下的任务（幂等，已迁移数据保持最新）。迁移后旧日程 UI 不再展示。

### Q: 任务卡的到期提醒什么时候发送？
打开任务卡窗口 → 设置 →「提醒偏好」，可配置截止前一天 / 当天 / 逾期每日的提醒（默认 09:00 发送一次，依赖系统通知）。也可点击「立即检查」手动发送当前应提醒的到期/逾期任务。

### Q: 「看日记」为什么从书库首页变成了独立窗口？
v1.5.0 起「看日记」由页内书页弹窗升级为**独立窗口**（翻书浏览全部日记，仅展示只读），与世界观、版本历史等独立窗口一致，支持多窗口并行使用。写作中的主窗口不会被遮挡。

## Agent 自动化相关

### Q: Agent 面板提示异常怎么办？

Agent 已内置为 Rust 原生引擎，无需安装或启动。若面板异常，请检查「设置 → AI 配置」中的 API Key 是否有效，或用「测试连接」验证网络。

### Q: Agent 需要联网吗？

需要。Agent 全部技能使用「设置 → AI 配置」中配置的云端对话模型（智谱 / DeepSeek / OpenAI 兼容），不再依赖本地 Ollama / Python 环境。

### Q: Agent 会修改我的章节内容吗？

**不会。** Agent 引擎只能通过内置只读工具读取章节与世界观资料。所有写操作（保存、恢复快照等）的唯一入口始终在 Rust 命令层。Agent 的输出以文本形式展示，是否采纳由你决定。

### Q: Agent 记忆保存在哪里？可以删除吗？

保存在主数据库 `time_write.db` 的 `memories` 表中（v1.1 起并入主库，旧独立库 `agent_memory.db` 启动时自动迁移），按作品隔离。可在 Agent 面板点击「记忆」按钮查看、编辑、删除单条记忆，或清空当前作品的全部记忆。

### Q: Agent 和 AI 助手有什么区别？

AI 助手是多轮对话工具（v1.2 起同样由 Rust Agent 引擎驱动，上下文经引擎工具检索，RAG 后端为预留能力）；Agent 会自主规划、多步调用 6 个数据库工具完成复杂任务，并拥有跨会话的三层记忆体。详见 [Agent 自动化](user-guide/agent-panel)。

## 开发相关

### Q: 开发环境需要什么？
- Node.js ≥ 22
- pnpm ≥ 11
- Rust 最新稳定版
- macOS / Windows / Linux

> v1.1 起 Agent 为 Rust 原生引擎，开发与运行均无需 Python。

### Q: 如何调试 Rust 后端？
使用 `pnpm tauri dev` 启动开发模式，Rust 代码的 `println!` 输出会出现在终端中。

### Q: 如何添加新的 IPC 命令？
1. 在 `src-tauri/src/commands/` 添加命令函数
2. 在 `mod.rs` 中声明模块
3. 在 `lib.rs` 中注册命令
4. 在 `src/lib/tauri-bridge.ts` 中添加前端封装

### Q: 如何添加新的 Tauri 插件？
1. 在 `Cargo.toml` 添加插件依赖
2. 在 `lib.rs` 中注册插件
3. 在 `capabilities/default.json` 中配置权限

### Q: 为什么构建失败？
运行 `pnpm check` 完整性检测脚本，确认所有文件结构完整。

### Q: 如何自定义主题？
主题通过 `src/styles/theme.css` 中的 CSS 变量控制。可修改 HSL 值自定义颜色方案。
