# 04 — 事件系统与跨窗口通信

## 4.1 通信体系总览

```
┌───────────────────────────────────────────┐
│              Tauri Event System            │
│                                           │
│  ┌─────────┐  emit   ┌─────────┐         │
│  │  Rust    │ ──────► │ Window A│ listen  │
│  │ Backend  │ ──────► │ Window B│ listen  │
│  │          │ ──────► │ Window C│ listen  │
│  └────┬─────┘         └─────────┘         │
│       │                                    │
│       │ invoke (request/response)          │
│       ▼                                    │
│  ┌─────────┐  emit_and_wait  ┌─────────┐  │
│  │ Window A│ ◄──────────────►│ Window B│  │
│  └─────────┘    (via Rust)   └─────────┘  │
└───────────────────────────────────────────┘
```

| 模式           | 方向             | 协议        | 场景                       |
| -------------- | ---------------- | ----------- | -------------------------- |
| IPC Command    | Window → Rust    | invoke      | 数据 CRUD、业务操作        |
| Global Event   | Rust → All Windows| emit/listen | 领域数据变更广播           |
| Window Event   | Rust → Target Win| emit_to     | 定向通知（状态、错误）      |
| RPC            | Window ↔ Window  | invoke+reply| 模态窗口交互               |

## 4.2 事件命名规范

### 4.2.1 格式

```
{module}:{entity}:{action}[:{scope}]
```

### 4.2.2 字段定义

| 片段   | 约束              | 示例                 |
| ------ | ----------------- | -------------------- |
| module | 小写、单数        | `article`, `project` |
| entity | 小写、单数        | `article`, `draft`   |
| action | 过去式动词        | `created`, `updated` |
| scope  | 可选，`all`/label | `all`, `editor-1`    |

### 4.2.3 标准动作动词

| 动词      | 含义         | 示例                              |
| --------- | ------------ | --------------------------------- |
| `created` | 实体创建     | `project:project:created`         |
| `updated` | 实体更新     | `article:article:updated`         |
| `deleted` | 实体删除     | `article:draft:deleted`           |
| `moved`   | 实体移动     | `article:article:moved`           |
| `renamed` | 实体重命名   | `project:project:renamed`         |
| `changed` | 全局配置变更 | `config:theme:changed:all`        |
| `synced`  | 同步完成     | `sync:offline:queue:synced`       |

### 4.2.4 完整事件目录

```
article:article:created           # 文章创建
article:article:updated           # 文章内容更新
article:article:deleted           # 文章删除
article:article:moved             # 文章移动到其他项目
article:draft:auto-saved          # 草稿自动保存
article:draft:discarded           # 草稿丢弃
project:project:created           # 项目创建
project:project:updated           # 项目信息更新
project:project:deleted           # 项目删除
project:project:renamed           # 项目重命名
config:theme:changed:all          # 主题切换（全局）
config:font:changed:all           # 字体变更（全局）
agent:stream:chunk                # Agent 流式输出帧
agent:status:changed              # Agent 状态变更
agent:skill:completed             # Skill 执行完成
sync:offline:queue:changed        # 离线队列变更

```

## 4.3 Rust 侧事件发射

### 4.3.1 EventEmitter 模块

```rust
// events/emitter.rs
use tauri::{AppHandle, Emitter};
use std::sync::Arc;

pub struct EventEmitter {
    app: AppHandle,
}

impl EventEmitter {
    pub fn new(app: AppHandle) -> Self {
        Self { app }
    }

    /// 发射领域变更事件到所有窗口
    pub fn emit_entity_updated<T: Serialize>(
        &self,
        entity_type: &str,
        payload: &T,
    ) {
        let event_name = format!("{entity_type}:{entity_type}:updated");
        let _ = self.app.emit(&event_name, payload);
    }

    /// 定向发送到指定窗口
    pub fn emit_to_window<T: Serialize>(
        &self,
        window_label: &str,
        event: &str,
        payload: &T,
    ) -> Result<(), AppError> {
        if let Some(window) = self.app.get_webview_window(window_label) {
            window.emit(event, payload)?;
        }
        Ok(())
    }
}
```

### 4.3.2 去重发射器

```rust
// events/dedup_emitter.rs
use std::collections::HashSet;
use std::sync::Mutex;
use std::time::{Duration, Instant};
use std::collections::hash_map::DefaultHasher;
use std::hash::{Hash, Hasher};

type EventKey = (String, u64);

static RECENT_EVENTS: Lazy<Mutex<HashSet<EventKey>>> =
    Lazy::new(|| Mutex::new(HashSet::new()));

const DEDUP_WINDOW_MS: u64 = 300;

pub fn emit_deduped<T: Serialize>(
    app: &AppHandle,
    event: &str,
    payload: &T,
) {
    let json = serde_json::to_string(payload).unwrap_or_default();
    let mut hasher = DefaultHasher::new();
    json.hash(&mut hasher);
    let hash = hasher.finish();

    let key: EventKey = (event.to_string(), hash);
    let mut recent = RECENT_EVENTS.lock().unwrap();

    if recent.contains(&key) {
        return; // 去重：300ms 内相同内容已发送过
    }

    recent.insert(key.clone());
    let _ = app.emit(event, &json);

    // 300ms 后自动清理，防止内存无限增长
    let key_clone = key.clone();
    std::thread::spawn(move || {
        std::thread::sleep(Duration::from_millis(DEDUP_WINDOW_MS));
        RECENT_EVENTS.lock().unwrap().remove(&key_clone);
    });
}
```

**并发安全说明**：
- `Mutex<HashSet>` 保护共享状态
- 每个清理任务在独立线程执行，不阻塞 emit
- `lazy_static` 确保全局唯一实例
- 极端并发下（>1000 emit/s），HashSet 锁竞争可接受（纳秒级）

## 4.4 事件分级

| 级别 | 频率       | 策略                | 示例              |
| ---- | ---------- | ------------------- | ----------------- |
| L1   | < 1/秒     | 即时 emit + 去重    | CRUD、重命名      |
| L2   | 1-10/秒    | Debounce 100ms + 去重| 批量导入进度       |
| L3   | > 10/秒    | 仅窗口内，不广播    | 打字、拖拽、滚动  |

### L3 高频事件处理

```typescript
// L3 事件：仅当前窗口 useReducer 处理
const [cursorPos, setCursorPos] = useState({ line: 0, col: 0 });

// 绝不 emit 到全局
const handleTyping = useCallback((e: React.KeyboardEvent) => {
  setCursorPos({ line: getLine(e), col: getCol(e) });
}, []);
```

## 4.5 前端事件监听

### 4.5.1 领域事件监听器

```typescript
// core/services/eventListener.ts
import { listen, UnlistenFn } from '@tauri-apps/api/event';
import type { ArticleDTO, ProjectDTO } from '@/modules/domain';

type EventHandler<T> = (payload: T) => void;

class EventListenerService {
  private unlisteners: UnlistenFn[] = [];

  /// 注册领域事件监听，自动 dispatch 到 Store
  listenToDomainEvents(
    store: AppStore,              // 窗口本地 Store
    windowLabel: string
  ): UnlistenFn[] {
    const handlers: Array<[string, EventHandler<any>]> = [
      [
        'article:article:updated',
        (p: ArticleDTO) => store.dispatch(articleUpserted(p)),
      ],
      [
        'article:article:created',
        (p: ArticleDTO) => store.dispatch(articleUpserted(p)),
      ],
      [
        'article:article:deleted',
        (p: { id: string }) => store.dispatch(articleDeleted(p.id)),
      ],
      [
        'project:project:updated',
        (p: ProjectDTO) => store.dispatch(projectUpserted(p)),
      ],
      [
        'config:theme:changed:all',
        (p: { theme: string }) => store.dispatch(themeChanged(p.theme)),
      ],
    ];

    // 异步注册所有监听
    const unlisteners = handlers.map(([event, handler]) => {
      const unlisten = listen(event, (e) => handler(e.payload));
      return async () => (await unlisten)();
    });

    this.unlisteners.push(...unlisteners);
    return unlisteners;
  }

  /// 窗口卸载时清理
  async destroy() {
    await Promise.all(this.unlisteners.map(fn => fn()));
    this.unlisteners = [];
  }
}

export const eventListenerService = new EventListenerService();
```

### 4.5.2 前端防抖

```typescript
// core/services/debouncedListener.ts
import { debounce } from 'lodash';

export function createDebouncedListener<T>(
  event: string,
  handler: (payload: T) => void,
  waitMs: number = 100,
): UnlistenFn {
  const debounced = debounce(handler, waitMs, {
    leading: false,
    trailing: true,
  });

  return listen<T>(event, (e) => debounced(e.payload));
}
```

## 4.6 跨窗口 RPC

### 4.6.1 架构

```
Window A (caller)
  │ invoke('rpc:call', { target: 'Window B', method, params })
  ▼
Rust RPC Router
  ├─ 解析 target
  ├─ 权限校验
  ├─ emit_and_wait → Window B
  └─ reply → Window A
```

### 4.6.2 Rust 实现

```rust
// commands/rpc_commands.rs
use std::collections::HashMap;
use tauri::Emitter;

#[tauri::command]
async fn rpc_call(
    app: AppHandle,
    target: String,
    method: String,
    params: serde_json::Value,
) -> Result<serde_json::Value, String> {
    // 超时 30s
    let timeout = Duration::from_secs(30);

    // 生成请求 ID
    let request_id = uuid::Uuid::new_v4().to_string();
    let request_payload = serde_json::json!({
        "request_id": request_id,
        "method": method,
        "params": params,
    });

    // 发送到目标窗口
    let target_window = app.get_webview_window(&target)
        .ok_or("Target window not found")?;

    // 使用 oneshot channel 等待回复
    let (tx, rx) = tokio::sync::oneshot::channel();

    // 注册临时回复监听
    let app_clone = app.clone();
    let request_id_clone = request_id.clone();
    let unlisten = app.listen_global(
        format!("rpc:reply:{request_id}"),
        move |event| {
            let _ = tx.send(event.payload().to_string());
        },
    );

    target_window.emit("rpc:request", &request_payload)
        .map_err(|e| e.to_string())?;

    // 等待回复或超时
    let result = tokio::time::timeout(timeout, rx).await
        .map_err(|_| "RPC timeout")?
        .map_err(|_| "RPC channel closed")?;

    // 清理临时监听
    app_clone.unlisten(unlisten);

    Ok(serde_json::from_str(&result).unwrap_or_default())
}
```

### 4.6.3 前端 Caller

```typescript
// core/services/rpcClient.ts
import { invoke } from '@tauri-apps/api/core';

export async function rpcCall<T = unknown>(
  targetWindow: string,
  method: string,
  params: Record<string, unknown>,
): Promise<T> {
  return invoke<T>('rpc_call', {
    target: targetWindow,
    method,
    params: JSON.stringify(params),
  });
}

// 使用示例：模态选择器
const selectedItem = await rpcCall<ArticleDTO>(
  'picker-window',
  'select_article',
  { projectId: 'proj-1' }
);
```

// 目标窗口注册 RPC 处理器
import { listen } from '@tauri-apps/api/event';
import { emit } from '@tauri-apps/api/event';

listen<RpcRequest>('rpc:request', async (event) => {
  const { request_id, method, params } = event.payload;

  try {
    const result = await handleRpcMethod(method, params);
    await emit(`rpc:reply:${request_id}`, { ok: true, data: result });
  } catch (error) {
    await emit(`rpc:reply:${request_id}`, { ok: false, error: String(error) });
  }

## 4.7 事件可靠性保证

| 保障             | 机制                                       |
| ---------------- | ------------------------------------------ |
| 去重             | 300ms 窗口 + 内容哈希                      |
| 防抖             | 前端 100ms debounce                        |
| 有序性           | Tauri Event 底层保证 FIFO                   |
| 遗漏检测         | 窗口聚焦时触发全量同步（增量基于 version） |
| 异常恢复         | 监听器断连时自动重连（指数退避）           |
| 内存控制         | 去重 HashSet 300ms 自动清理                |

## 4.8 故障模式

| 故障               | 影响                   | 处理                       |
| ------------------ | ---------------------- | -------------------------- |
| 事件 lost（极罕见） | 窗口数据不一致         | 聚焦时全量同步 + version diff |
| 事件重复（已去重）  | 浪费 dispatch          | 去重机制覆盖               |
| RPC 超时            | 模态窗口卡住           | 30s 超时 + 错误提示        |
| 目标窗口不存在       | RPC 失败               | 返回明确错误               |
