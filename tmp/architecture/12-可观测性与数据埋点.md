# 12 — 可观测性与数据埋点

## 12.1 设计目标与原则

### 12.1.1 目标矩阵

| 维度 | 目标 | 度量标准 |
|------|------|---------|
| 功能使用分析 | 掌握各功能的真实使用率，指导迭代优先级 | 周活跃功能排名 |
| 性能监控 | 感知全链路延迟劣化趋势 | P50/P95/P99 延迟曲线 |
| 错误追踪 | 第一时间发现并定位崩溃和异常 | 崩溃率 < 0.5% / 错误率 < 2% |
| AI 质量度量 | 衡量 AI 技能的效果与成本 | 采纳率、平均耗时、Token 消耗 |
| 问题诊断 | 用户反馈问题时快速还原现场 | 日志回溯 ≤ 5 分钟 |

### 12.1.2 设计原则

| # | 原则 | 说明 |
|---|------|------|
| 1 | **本地优先** | 所有事件先写入本地存储，再异步上报；网络不可用时零丢失 |
| 2 | **隐私默认** | 用户内容（文章、项目名）绝不离开设备；用户可随时查看/删除/关闭 |
| 3 | **最小开销** | 埋点代码对主路径延迟影响 < 1ms；后台线程批量写入，不阻塞 UI |
| 4 | **结构化** | 所有事件遵循统一 schema，可跨层关联（session_id / trace_id） |

> **与审计日志（06 §6.3.5）的分工**：审计日志关注**谁在什么时候做了什么**（安全合规），埋点关注**功能用得怎么样**（产品迭代）。两者分表存储、独立清理。

## 12.2 领域建模：统一事件模型

### 12.2.1 事件分类体系

```
TelemetryEvent (统一基类)
├── UserAction     — 用户操作行为
│   ├── click, hover, scroll
│   ├── save, delete, export
│   └── skill_execute, skill_cancel
├── Performance    — 性能指标
│   ├── page_load, ipc_roundtrip
│   ├── ai_inference_duration
│   └── first_contentful_paint
├── Error          — 异常与崩溃
│   ├── panic (Rust)
│   ├── unhandled_rejection (TS)
│   └── agent_crash (Python)
├── Business       — 业务指标
│   ├── article_count, project_count
│   ├── daily_active_minutes
│   └── skill_adoption_rate
└── System         — 应用生命周期
    ├── app_start, app_close
    ├── window_create, window_focus
    └── agent_status_change
```

### 12.2.2 事件与日志分级对照

| 日志级别 | 用途 | 是否上报 | 示例 |
|---------|------|---------|------|
| `DEBUG` | 开发调试，不写入持久存储 | ❌ | 变量值、状态转换细节 |
| `INFO` | 用户行为事件、业务指标 | ✅（采样/聚合） | `article:save`, `skill:execute` |
| `WARN` | 可恢复异常、降级行为 | ✅ | 模型降级、离线切换 |
| `ERROR` | 不可恢复错误、崩溃 | ✅（全量） | `IPC_TIMEOUT`, `panic` |
| `FATAL` | 数据损坏、安全违规 | ✅（实时） | `DB_CORRUPTION`, `SECURITY_TAMPERING` |

### 12.2.3 TelemetryEvent 结构（Rust 定义）

```rust
// telemetry/event.rs
use serde::{Serialize, Deserialize};
use std::collections::HashMap;

/// 事件来源层
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "snake_case")]
pub enum EventSource {
    Frontend,
    Rust,
    Python,
}

/// 事件类别
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "snake_case")]
pub enum EventCategory {
    UserAction,
    Performance,
    Error,
    Business,
    System,
}

/// 统一埋点事件
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct TelemetryEvent {
    /// 事件唯一 ID（UUID v7，可按时间排序）
    pub event_id: String,
    /// 事件发生时间（ISO 8601）
    pub timestamp: String,
    /// 事件来源层
    pub source: EventSource,
    /// 事件类别
    pub category: EventCategory,
    /// 事件名（点分隔命名），e.g. "article.save.clicked"
    pub name: String,
    /// 结构化属性
    #[serde(default)]
    pub properties: HashMap<String, serde_json::Value>,

    // ─── 关联维度 ───
    /// 应用会话 ID（应用启动后分配，关闭后失效）
    pub session_id: String,
    /// 窗口标签（多窗口场景，关联到具体窗口）
    pub window_label: Option<String>,
    /// 分布式追踪 ID（跨层关联用，Rust 生成传递到 TS/Python）
    pub trace_id: Option<String>,

    // ─── 环境维度 ───
    /// 应用版本号
    pub app_version: String,
    /// 操作系统，e.g. "macos 14.5"
    pub os_info: String,
    /// 设备架构
    pub arch: String,

    // ─── 用户维度（匿名化） ───
    /// 匿名用户 ID（安装时生成，SHA-256 哈希后存储）
    pub user_anonymous_id: String,
}
```

#### Tracker SDK

```typescript
// analytics/tracker.ts

type EventCategory = 'user_action' | 'performance' | 'error' | 'business' | 'system';

interface TrackPayload {
  name: string;
  category?: EventCategory;
  properties?: Record<string, unknown>;
  windowLabel?: string;
}

class TelemetryTracker {
  private sessionId: string;
  private buffer: TrackPayload[] = [];
  private flushTimer: ReturnType<typeof setInterval> | null = null;
  private readonly BATCH_SIZE = 20;
  private readonly FLUSH_INTERVAL_MS = 5000;

  constructor() {
    this.sessionId = crypto.randomUUID();
    this.startAutoFlush();
  }

  /** 核心 API：发送事件 */
  track(name: string, properties?: Record<string, unknown>, category: EventCategory = 'user_action') {
    this.buffer.push({ name, category, properties });

    // 错误事件立即发送
    if (category === 'error') {
      this.flush();
    } else if (this.buffer.length >= this.BATCH_SIZE) {
      this.flush();
    }
  }

  /** 页面浏览（自动采集） */
  page(name: string) {
    this.track('page.view', { page: name }, 'user_action');
  }

  /** 性能计时 */
  timing(name: string, durationMs: number) {
    this.track(name, { duration_ms: durationMs }, 'performance');
  }

  /** 错误上报 */
  error(error: Error, context?: string) {
    this.track('error.unhandled', {
      message: error.message,
      stack: error.stack?.split('\n').slice(0, 5).join('\n'), // 只取前 5 帧
      context,
    }, 'error');
  }

  /** 设置用户匿名 ID（安装时分配） */
  identify(anonymousId: string) {
    // 用户 ID 不暴露在事件中，仅 Rust 侧附加（哈希后）
  }

  // ─── 内部 ───

  private async flush() {
    if (this.buffer.length === 0) return;
    const batch = this.buffer.splice(0, this.BATCH_SIZE);
    try {
      await invoke('telemetry:track_batch', {
        events: batch.map(e => ({
          ...e,
          session_id: this.sessionId,
          timestamp: new Date().toISOString(),
        })),
      });
    } catch {
      // invoke 失败时静默——离线场景已在 Rust 侧处理
    }
  }

  private startAutoFlush() {
    this.flushTimer = setInterval(() => this.flush(), this.FLUSH_INTERVAL_MS);
  }

  /** 应用关闭前最后一次冲刷 */
  async shutdown() {
    if (this.flushTimer) clearInterval(this.flushTimer);
    await this.flush();
  }
}

// 全局单例
export const telemetry = new TelemetryTracker();
```

```rust
use std::time::Instant;
use tauri::Runtime;

/// 包装 Tauri Command，自动记录执行耗时
pub async fn with_telemetry<R: Runtime, T, E: Serialize>(
    command_name: &str,
    future: impl Future<Output = Result<T, E>>,
) -> Result<T, E> {
    let start = Instant::now();
    let result = future.await;
    let elapsed_ms = start.elapsed().as_millis() as u64;

    match &result {
        Ok(_) => {
            tracing::info!(
                command = command_name,
                duration_ms = elapsed_ms,
                status = "ok"
            );
        }
        Err(e) => {
            tracing::warn!(
                command = command_name,
                duration_ms = elapsed_ms,
                status = "error",
                error = %serde_json::to_string(e).unwrap_or_default()
            );
        }
    }

    result
}

// 使用：

        // 原有业务逻辑
    }).await
```

```rust
// telemetry/panic_hook.rs
use std::panic;

pub fn install_panic_hook(telemetry_bus: Arc<TelemetryBus>) {
    let bus = telemetry_bus.clone();
    panic::set_hook(Box::new(move |info| {
        let payload = info.payload();
        let msg = payload
            .downcast_ref::<&str>()
            .map(|s| s.to_string())
            .or_else(|| payload.downcast_ref::<String>().cloned())
            .unwrap_or_else(|| "Unknown panic".into());

        let location = info
            .location()
            .map(|l| format!("{}:{}:{}", l.file(), l.line(), l.column()));

        // 紧急写入（同步，不依赖 async runtime）
        bus.record_sync(TelemetryEvent {
            name: "system.panic".into(),
            category: EventCategory::Error,
            properties: [
                ("message".into(), json!(msg)),
                ("location".into(), json!(location)),
            ].into(),
            ..TelemetryEvent::now(EventSource::Rust)
        });

        tracing::error!(panic_message = %msg, panic_location = ?location, "FATAL PANIC");
    }));
}
```

#### 结构化日志输出

```python
# agent/telemetry.py
import json
import time
import uuid
import logging
from typing import Optional
from dataclasses import dataclass, field, asdict

@dataclass
class AgentTelemetryEvent:
    name: str
    category: str  # "user_action" | "performance" | "error"
    properties: dict = field(default_factory=dict)
    event_id: str = field(default_factory=lambda: str(uuid.uuid4()))
    timestamp: str = field(default_factory=lambda: time.strftime("%Y-%m-%dT%H:%M:%S.%fZ"))
    source: str = "python"

    def to_stdout(self):
        """输出一行 JSON 到 stdout，Rust 侧捕获解析"""
        print(json.dumps(asdict(self), ensure_ascii=False), flush=True)


# ─── 使用示例 ───

class SkillExecutor:
    async def execute(self, request: SkillExecuteRequest):
        start = time.time()

        # 开始事件
        AgentTelemetryEvent(
            name="agent.skill.execute.started",
            category="user_action",
            properties={
                "skill": request.skill_type.value,
                "model": request.model,
                "message_count": len(request.messages),
            },
        ).to_stdout()

        try:
            result = await self._do_execute(request)
            elapsed = (time.time() - start) * 1000

            # 完成事件
            AgentTelemetryEvent(
                name="agent.skill.execute.completed",
                category="performance",
                properties={
                    "skill": request.skill_type.value,
                    "duration_ms": round(elapsed, 1),
                    "output_tokens": result.token_usage.get("completion_tokens", 0),
                    "total_tokens": result.token_usage.get("total_tokens", 0),
                },
            ).to_stdout()

            return result

        except Exception as e:
            elapsed = (time.time() - start) * 1000

            # 错误事件
            AgentTelemetryEvent(
                name="agent.skill.execute.errored",
                category="error",
                properties={
                    "skill": request.skill_type.value,
                    "duration_ms": round(elapsed, 1),
                    "error_type": type(e).__name__,
                    "error_message": str(e)[:200],
                },
            ).to_stdout()

            raise
```

```rust
// telemetry/python_stdout_capture.rs
use tokio::io::{AsyncBufReadExt, BufReader};
use std::process::Stdio;

impl PythonAgentManager {
    /// 捕获 Python 子进程 stdout 中的 JSON 事件，转发到 TelemetryBus
    fn capture_python_telemetry(
        stdout: impl AsyncRead + Unpin,
        bus: Arc<TelemetryBus>,
    ) {
        tokio::spawn(async move {
            let reader = BufReader::new(stdout);
            let mut lines = reader.lines();
            while let Ok(Some(line)) = lines.next_line().await {
                // 尝试解析 JSON 行
                if let Ok(event) = serde_json::from_str::<TelemetryEvent>(&line) {
                    if event.name.starts_with("agent.") {
                        bus.record(event);
                    }
                }
                // 非 JSON 行：作为普通日志处理
            }
        });
    }
}
```

```rust
// telemetry/storage_quota.rs
pub struct StorageQuota {
    /// SQLite 事件表最大行数
    pub max_sqlite_rows: u64,        // 默认 200,000
    /// 日志文件总占用上限（MB）
    pub max_log_disk_mb: u64,        // 默认 200
    /// 定期清理间隔
    pub cleanup_interval_hours: u64, // 默认 6
}

impl Default for StorageQuota {
    fn default() -> Self {
        Self {
            max_sqlite_rows: 200_000,
            max_log_disk_mb: 200,
            cleanup_interval_hours: 6,
        }
    }
}

impl TelemetryCleaner {
    pub fn cleanup(&self, conn: &Connection, quota: &StorageQuota) -> Result<(), AppError> {
        // 策略 1：删除已上报且超过 30 天的事件
        let deleted = conn.execute(
            "DELETE FROM telemetry_events
             WHERE uploaded = 1
               AND created_at < datetime('now', '-30 days')",
            [],
        )?;
        if deleted > 0 {
            tracing::info!("Cleaned {deleted} uploaded telemetry events (age > 30d)");
        }

        // 策略 2：若仍超配额，删除最旧的已上报事件
        let row_count: i64 = conn.query_row(
            "SELECT COUNT(*) FROM telemetry_events", [], |r| r.get(0)
        )?;
        if row_count as u64 > quota.max_sqlite_rows {
            let overflow = (row_count as u64 - quota.max_sqlite_rows).min(5000);
            conn.execute(
                "DELETE FROM telemetry_events WHERE event_id IN (
                    SELECT event_id FROM telemetry_events
                    WHERE uploaded = 1
                    ORDER BY created_at ASC LIMIT ?1
                )",
                params![overflow],
            )?;
            tracing::warn!("Telemetry row quota exceeded, removed {overflow} oldest events");
        }

        // 策略 3：清理过期日志文件
        Self::cleanup_log_files(&quota);

        Ok(())
    }

    fn cleanup_log_files(quota: &StorageQuota) {
        let log_dir = &quota_log_directory();
        let cutoff = SystemTime::now() - Duration::from_secs(
            quota.max_log_days() as u64 * 86400
        );

        if let Ok(entries) = std::fs::read_dir(log_dir) {
            for entry in entries.flatten() {
                if let Ok(metadata) = entry.metadata() {
                    if let Ok(modified) = metadata.modified() {
                        if modified < cutoff {
                            let _ = std::fs::remove_file(entry.path());
                        }
                    }
                }
            }
        }
    }
}
```

### 12.5.3 重试与幂等性

```rust
// telemetry/uploader.rs (续)
use std::time::Duration;
use rand::Rng;

impl TelemetryUploader {
    async fn upload_batch(&self, events: &[TelemetryEvent]) -> Result<(), UploadError> {
        let batch_id = Uuid::new_v4().to_string();

        let payload = BatchPayload {
            batch_id: batch_id.clone(),
            client_info: self.client_info(),
            events: events.to_vec(),
            sent_at: Utc::now().to_rfc3339(),
        };

        let response = self.http_client
            .post(&self.config.endpoint)
            .json(&payload)
            .header("X-MirageInk-Version", &self.app_version)
            .header("X-MirageInk-Client-Id", &self.user_anonymous_id)
            .timeout(Duration::from_secs(30))
            .send()
            .await?;

        match response.status() {
            StatusCode::OK | StatusCode::CREATED => {
                self.mark_uploaded(events).await?;
                Ok(())
            }
            StatusCode::TOO_MANY_REQUESTS => {
                Err(UploadError::RateLimited)
            }
            status if status.is_server_error() => {
                Err(UploadError::ServerError(status.as_u16()))
            }
            status => {
                Err(UploadError::UnexpectedStatus(status.as_u16()))
            }
        }
    }

    /// 指数退避重试，带 jitter
    async fn upload_with_retry(&self, events: Vec<TelemetryEvent>) {
        let mut retries = 0;
        let mut delay = Duration::from_secs(30); // 初始 30s

        loop {
            match self.upload_batch(&events).await {
                Ok(()) => {
                    tracing::info!("Telemetry uploaded: {} events", events.len());
                    return;
                }
                Err(UploadError::RateLimited) if retries < self.config.max_retries => {
                    // 频率限制：退避 1min × 2^retry
                    delay = Duration::from_secs(60) * 2u32.pow(retries);
                    tracing::warn!("Telemetry rate limited, retry in {:?}", delay);
                }
                Err(_) if retries < self.config.max_retries => {
                    // 指数退避：30s × 2^retry + jitter
                    let jitter = rand::thread_rng().gen_range(0..5000);
                    delay = Duration::from_secs(30) * 2u32.pow(retries)
                        + Duration::from_millis(jitter);
                    tracing::warn!("Telemetry upload failed (retry {}/{}), next in {:?}",
                        retries + 1, self.config.max_retries, delay);
                }
                Err(e) => {
                    tracing::error!("Telemetry upload failed after {} retries: {}", retries, e);
                    // 标记 retry_count 递增，等待下次定时器触发
                    self.increment_retry_count(&events).await;
                    return;
                }
            }

            retries += 1;
            tokio::time::sleep(delay).await;
        }
    }
}
```

**幂等性保证**：服务端通过 `batch_id` 去重。若客户端收到 200 但未成功标记本地 `uploaded`（崩溃），下次上传时带相同 `batch_id`，服务端返回 200（已存在）。

### 12.6.1 数据分级

|------|------|---------|---------|

| **匿名 ID** | SHA-256(安装 UUID) | ✅ | 无个人识别能力，仅用于聚合统计 |
| **运行环境** | 操作系统版本、CPU 架构、App 版本 | ✅ | 去敏后上报 |
| **使用行为** | 功能点击次数、使用时长、AI 技能调用 | ✅ | 去敏后上报 |
| **性能指标** | 页面加载时间、IPC 延迟、Token 消耗 | ✅ | 去敏后上报 |
| **错误堆栈** | 崩溃/异常调用栈 | ✅ | 路径去敏后上报 |

### 12.6.2 Rust 侧脱敏实现

```rust
// telemetry/sanitizer.rs

pub struct EventSanitizer;

impl EventSanitizer {
    /// 脱敏入口：在上报前调用
    pub fn sanitize(event: &mut TelemetryEvent) {
        // 规则 1：移除绝对文件路径
        if let Some(prop) = event.properties.get_mut("stack") {
            if let Some(stack) = prop.as_str() {
                *prop = json!(Self::sanitize_stack_trace(stack));
            }
        }

        // 规则 2：移除可能包含个人信息的 property key
        let blocked_keys = ["content", "title", "text", "name", "email", "ip"];
        event.properties.retain(|k, _| !blocked_keys.iter().any(|bk| k.contains(bk)));

        // 规则 3：截断过长字符串
        for (_, v) in event.properties.iter_mut() {
            if let Some(s) = v.as_str() {
                if s.len() > 500 {
                    *v = json!(format!("{}...(truncated)", &s[..500]));
                }
            }
        }
    }

    fn sanitize_stack_trace(stack: &str) -> String {
        // 将 /Users/alice/projects/mirageink/src/main.rs:42
        // → src/main.rs:42
        stack.lines()
            .map(|line| {
                // 替换绝对路径为相对路径
                // 简单策略：去掉到 src/ 之前的所有路径
                if let Some(pos) = line.find("/src/") {
                    format!("src/{}", &line[pos + 5..])
                } else {
                    line.to_string()
                }
            })
            .collect::<Vec<_>>()
            .join("\n")
    }
}
```
