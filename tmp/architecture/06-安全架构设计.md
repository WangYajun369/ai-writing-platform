# 06 — 安全架构设计

## 6.1 威胁模型

### 6.1.1 信任边界

```
┌────── 不信任 ────────────────────────────┐
│  WebView (React) ← 可见但不可信            │
│  - 用户可控的 DOM / JS                    │
│  - 可能被 DevTools 篡改                    │
│  - 不能信任前端传来的任何数据              │
┝━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┥
│  Rust Application ← 信任边界              │
│  - 所有校验在此层执行                      │
│  - 权限最终裁决                            │
│  - SQLite 独占访问                         │
┝━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┥
│  Python Agent (子进程) ← 部分信任          │
│  - API Key 不直接暴露                      │
│  - 数据通过 Bridge 回调，不直连 DB         │
│  - 输入需 Pydantic 校验                   │
└───────────────────────────────────────────┘
```

### 6.1.2 攻击面分析

| 攻击面                 | 风险等级 | 影响                     |
| ---------------------- | -------- | ------------------------ |
| IPC 参数篡改           | HIGH     | 绕过业务规则             |
| Tauri Event 伪造       | MEDIUM   | 前端状态污染             |
| DevTools 注入          | MEDIUM   | 绕过前端校验             |
| Python HTTP 端点暴露   | LOW      | 127.0.0.1 仅环回          |
| SQLite 直接读写        | CRITICAL | 数据完整性破坏           |
| 内存中的 API Key       | MEDIUM   | Key 泄漏                 |
| Session Token 劫持     | MEDIUM   | 跨窗口越权               |

## 6.2 认证与会话管理

### 6.2.1 SessionManager

```rust
// security/session.rs
use std::collections::HashMap;
use std::sync::RwLock;
use uuid::Uuid;

pub struct Session {
    pub id: String,
    pub user_id: String,
    pub role: UserRole,
    pub window_labels: Vec<String>,   // 该会话关联的窗口
    pub created_at: DateTime<Utc>,
    pub expires_at: DateTime<Utc>,
}

pub struct SessionManager {
    sessions: RwLock<HashMap<String, Session>>,       // session_id → Session
    window_map: RwLock<HashMap<String, String>>,      // window_label → session_id
}

impl SessionManager {
    /// 创建新会话
    pub fn create_session(&self, user_id: &str, role: UserRole) -> Session {
        let session = Session {
            id: Uuid::new_v4().to_string(),
            user_id: user_id.to_string(),
            role,
            window_labels: vec![],
            created_at: Utc::now(),
            expires_at: Utc::now() + Duration::hours(24),
        };
        self.sessions.write().unwrap()
            .insert(session.id.clone(), session.clone());
        session
    }

    /// 将窗口与会话关联
    pub fn bind_window(&self, session_id: &str, window_label: &str) -> Result<(), AppError> {
        let mut sessions = self.sessions.write().unwrap();
        let mut window_map = self.window_map.write().unwrap();

        let session = sessions.get_mut(session_id)
            .ok_or(AppError::SessionNotFound)?;

        if Utc::now() > session.expires_at {
            return Err(AppError::SessionExpired);
        }

        session.window_labels.push(window_label.to_string());
        window_map.insert(window_label.to_string(), session_id.to_string());
        Ok(())
    }

    /// 根据窗口标签解析会话
    pub fn resolve_from_window(&self, window_label: &str) -> Option<Session> {
        let window_map = self.window_map.read().unwrap();
        let session_id = window_map.get(window_label)?;
        let sessions = self.sessions.read().unwrap();
        sessions.get(session_id).cloned()
    }

    /// 窗口关闭时解绑
    pub fn unbind_window(&self, window_label: &str) {
        let mut window_map = self.window_map.write().unwrap();
        if let Some(session_id) = window_map.remove(window_label) {
            let mut sessions = self.sessions.write().unwrap();
            if let Some(session) = sessions.get_mut(&session_id) {
                session.window_labels.retain(|l| l != window_label);
                // 如果没有关联窗口，清除会话
                if session.window_labels.is_empty() {
                    sessions.remove(&session_id);
                }
            }
        }
    }
}
```

### 6.2.2 安全存储 (Secure Store)

```rust
// security/secure_store.rs
use tauri::Manager;
use keyring::Entry;

pub struct SecureStore {
    service_name: String,
}

impl SecureStore {
    pub fn new() -> Self {
        Self {
            service_name: "mirageink".to_string(),
        }
    }

    /// 存储敏感数据（API Key、Token 等）
    pub fn store_secret(&self, key: &str, value: &str) -> Result<(), AppError> {
        let entry = Entry::new(&self.service_name, key)
            .map_err(|e| AppError::SecureStore(e.to_string()))?;
        entry.set_secret(value)
            .map_err(|e| AppError::SecureStore(e.to_string()))?;
        Ok(())
    }

    /// 读取敏感数据
    pub fn get_secret(&self, key: &str) -> Result<String, AppError> {
        let entry = Entry::new(&self.service_name, key)
            .map_err(|e| AppError::SecureStore(e.to_string()))?;
        entry.get_secret()
            .map_err(|e| AppError::SecureStore(e.to_string()))?;
        Ok(secret)
    }
}
```

> macOS 使用 Keychain, Windows 使用 Credential Manager, Linux 使用 Secret Service。

## 6.3 权限控制 (RBAC)

### 6.3.1 角色与权限定义

```rust
// security/permissions.rs
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum UserRole {
    Admin,      // 完全访问
    Editor,     // 创建/编辑/删除自己的内容
    Viewer,     // 只读
}

#[derive(Debug, Clone, Hash, Eq, PartialEq)]
pub enum Permission {
    ArticleRead,
    ArticleWrite,
    ArticleDelete,
    ProjectRead,
    ProjectWrite,
    ProjectDelete,
    AgentAccess,
    ConfigRead,
    ConfigWrite,
    ExportData,
}

impl UserRole {
    pub fn permissions(&self) -> Vec<Permission> {
        match self {
            UserRole::Admin => vec![
                Permission::ArticleRead,
                Permission::ArticleWrite,
                Permission::ArticleDelete,
                Permission::ProjectRead,
                Permission::ProjectWrite,
                Permission::ProjectDelete,
                Permission::AgentAccess,
                Permission::ConfigRead,
                Permission::ConfigWrite,
                Permission::ExportData,
            ],
            UserRole::Editor => vec![
                Permission::ArticleRead,
                Permission::ArticleWrite,
                Permission::ProjectRead,
                Permission::AgentAccess,
                Permission::ConfigRead,
            ],
            UserRole::Viewer => vec![
                Permission::ArticleRead,
                Permission::ProjectRead,
                Permission::ConfigRead,
            ],
        }
    }
}
```

### 6.3.2 权限校验中间件

```rust
// security/auth.rs
pub struct AuthService;

impl AuthService {
    /// 权限校验入口：用于每个 Tauri Command
    pub fn check_permission(
        session: &Session,
        required: Permission,
        resource_owner: Option<&str>,  // 数据行级安全
    ) -> Result<(), AppError> {
        // 1. 检查会话过期
        if Utc::now() > session.expires_at {
            return Err(AppError::SessionExpired);
        }

        // 2. 检查角色权限
        let permissions = session.role.permissions();
        if !permissions.contains(&required) {
            return Err(AppError::Unauthorized(
                format!("Missing permission: {:?}", required)
            ));
        }

        // 3. 数据行级安全检查（非 Admin 只能操作自己的数据）
        if let Some(owner_id) = resource_owner {
            if session.role != UserRole::Admin && owner_id != session.user_id {
                return Err(AppError::Forbidden(
                    "Cannot access resource owned by another user".into()
                ));
            }
        }

        Ok(())
    }
}
```

### 6.3.3 在 Command 中的使用模式

```rust
#[tauri::command]
async fn article_update(
    state: State<'_, AppState>,
    window: Window,
    id: String,
    content: String,
) -> Result<ArticleDTO, String> {
    // Step 1: 解析会话
    let session = state.session_manager
        .resolve_from_window(window.label())
        .ok_or("UNAUTHORIZED")?;

    // Step 2: 权限校验
    let article = state.article_repo.find_by_id(&id)
        .map_err(|e| e.to_string())?;
    state.auth.check_permission(
        &session,
        Permission::ArticleWrite,
        Some(&article.user_id),  // 行级安全
    ).map_err(|e| e.to_string())?;

    // Step 3: 业务逻辑
    state.article_usecase
        .update_article(&id, &content)
        .map(|a| a.into())
        .map_err(|e| e.to_string())
}
```

// security/validation.rs
use validator::{Validate, ValidationError};

#[derive(Debug, Validate, Deserialize)]
pub struct CreateArticleRequest {
    #[validate(length(min = 1, max = 500))]
    pub title: String,

    #[validate(length(min = 1, max = 1_000_000))]
    pub content: String,

    #[validate(length(min = 1, max = 100))]
    pub project_id: String,

    #[validate(custom = "validate_safe_id")]
    pub tags: Vec<String>,
}

fn validate_safe_id(s: &str) -> Result<(), ValidationError> {
    if s.chars().all(|c| c.is_alphanumeric() || c == '-' || c == '_') {
        Ok(())
    } else {
        Err(ValidationError::new("unsafe_id"))
    }
}

## 6.5 SQLite 安全

### 6.5.1 数据库文件加密

```rust
// infrastructure/database.rs
use rusqlite::Connection;

pub fn open_database(path: &Path) -> Result<Connection, AppError> {
    let conn = Connection::open(path)?;

    // 启用 SQLCipher 加密（如果启用）
    #[cfg(feature = "sqlcipher")]
    {
        let key = get_encryption_key()?;
        conn.execute_batch(&format!("PRAGMA key = '{}';", key))?;
    }

    // 安全配置
    conn.execute_batch("
        PRAGMA journal_mode = WAL;
        PRAGMA foreign_keys = ON;
        PRAGMA busy_timeout = 5000;
        PRAGMA secure_delete = ON;
    ")?;

    Ok(conn)
}
```

### 6.5.2 SQL 注入防护

所有 SQL 使用参数化查询，绝不拼接字符串：

```rust
// 正确 ✅
conn.execute(
    "SELECT * FROM articles WHERE id = ?1",
    params![article_id],
)?;

// 错误 ❌ 绝不这样做
// conn.execute(&format!("SELECT * FROM articles WHERE id = '{}'", article_id), [])?;
```

pub struct AuditLogger;

impl AuditLogger {
    pub fn log(
        conn: &Connection,
        user_id: &str,
        action: &str,
        resource_type: &str,
        resource_id: &str,
        details: &str,
    ) {
        let _ = conn.execute(
            "INSERT INTO audit_log (user_id, action, resource_type, resource_id, details, created_at)

            params![user_id, action, resource_type, resource_id, details],
        );
    }
