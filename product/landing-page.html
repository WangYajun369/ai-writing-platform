✕ 老实人自己写

资料繁多，徒耗时间

网络上各种资料浩如烟海，自己去找的话不但浪费精力，而且容易偏废主题。有的作者为了精益求精，找资料的时间比写文章的时间都长。

没精力研究爆款写作技巧

热榜流行趋势几天一个样，而很多作者往往为了全勤就已经精疲力尽，完全没有心思去关心当下的热门趋势。即使有心思去关心，热榜这么多小说，一篇小说又这么多字，完全不能分析到位。

十几个小时憋出几千字

灵感枯竭，绞尽脑汁、头发掉光的憋出来几千字来保住自己的全勤，这种痛苦的写作方式只会消磨你的斗志和热情，让人难以坚持。

核心功能

为创作者打造的完整写作工具链

从书库管理到章节编辑，从 AI 辅助到 Agent 自动化，覆盖小说创作的全流程需求。

📚

书库管理

多作品管理，网格/列表双视图自由切换、虚拟化滚动。支持搜索、排序（时间/字数/书名），一键创建与删除作品，每部作品可设置独立封面。每日写作目标通过进度环实时可视化，误删数据进入回收站，支持随时恢复。

多作品管理 目标进度环 回收站恢复
✏️

章节编辑器

基于 TipTap v3 的专业富文本编辑，支持 H1-H3 标题、加粗、斜体、文字颜色、图片缩放、表格、36 种语言代码高亮、任务列表、KaTeX 数学公式。图片支持查看器与精确选区裁剪，卷-章节两级目录树，滚动与光标位置自动记忆。

TipTap 编辑器 数学公式 图片裁剪
💾

智能保存

双保险自动保存机制：300ms 防抖实时保存 + 3 分钟定时保障。配合版本快照系统，每次保存自动生成历史记录（auto / milestone 类型），支持随时预览与恢复到任意历史版本，底部状态栏实时显示保存状态。

自动保存 版本快照 历史恢复
🌍

世界观资料库

6 种卡片类型构建完整世界观：人物、地点、时间线、势力、物品、其他。支持 FTS5 全文搜索、标签分类与过滤。独立悬浮窗口模式（始终置顶，420×650），写作同时随时查阅设定。

6 种卡片 FTS5 全文搜索 悬浮窗口
📤

导入导出与备份

灵活的内容迁移：支持导出为 TXT、Markdown、HTML 三种格式；导入 TXT 自动通过正则识别章节分隔符，智能拆分长篇内容。数据备份采用 AES-256-GCM 加密（密钥不硬编码），支持全量/单作品导出与完整恢复。

TXT / MD / HTML 智能分章 加密备份
🎨

个性化定制

4 套 HSL CSS 变量主题：亮色/暗色/暖黄/豆沙绿，护眼模式轻松切换。全局字体任选、字体大小 12-24px 自由调整，编辑器显示宽度三档可选，作品列表网格尺寸随心调节，打造属于自己的写作环境。

4 套主题 多字体可选 护眼模式
🤖

Agent 自动化写作

v1.0.0 里程碑能力：内置 Python Agent 子系统（FastAPI + LangGraph ReAct），四大写作技能自动调用数据库工具链，读取章节、搜索世界观设定，多步推理完成大纲生成、文风分析、一致性校验。三层记忆体系统让 AI 记住你的创作偏好，越用越懂你。

LangGraph ReAct 记忆体系统 双模型路由
🔌

开放与安全

5 种独立悬浮窗口（世界观/版本历史/章节总结/AI 工具箱/调试控制台），插件系统提供 6 个扩展点。深度链接协议（com.ukcoder.timewrite://）支持外部唤起直达作品，更新包经 minisign 签名校验，备份加密存储，数据安全可信。

5 种悬浮窗口 插件系统 签名更新
AI 智能写作

大模型加持，突破创作瓶颈

多服务商支持：智谱 BigModel、DeepSeek 与自定义 OpenAI 兼容端点（含 Ollama 本地模型），流式对话即时响应。RAG 上下文检索让 AI 了解你的作品背景，生成内容更贴合设定。

💬

流式对话

SSE / NDJSON 双协议支持，AI 回复逐字输出。自动重试与网络容错（指数退避 + 60s 断流保底），长对话滑动窗口压缩，体验流畅稳定。

🔍

RAG 上下文检索

向量检索 + FTS5 双轨降级，自动将章节内容与世界观设定注入对话上下文，让 AI 的回答符合你的作品设定，生成不跑偏。

⚡

AI 工具箱

29 个预设快捷提示词，5 大分类：续写、润色、扩写、剧情推演、角色分析、章末总结等，一键触发，告别空白页焦虑。

🔧

灵活模型配置

智谱 glm-5.1（默认）、DeepSeek 思考模型、Ollama 本地模型随心切换。对话与 RAG 配置完全解耦，API Key 按服务商独立管理。

创作工作流

从灵感萌芽到大作完成

五步走，让你的创作之旅高效有序。

1

创建作品

设置书名、封面、作者信息，为你的新作建立一个专属空间，设定每日写作目标。

2

搭建框架

规划卷-章节结构，在世界观资料库中创建人物、地点、势力等设定卡片，并建立完整索引。

3

专注写作

进入专注模式，沉浸于富文本编辑器。自动保存 + 版本快照守护你的每一份灵感。

4

AI / Agent 赋能

遇到瓶颈？AI 对话续写润色，AI 工具箱一键调用，Agent 智能体自动完成大纲与校验，灵感源源不断。

5

导出发布

导出为 TXT、Markdown 或 HTML 无缝衔接发布平台，加密备份让你的心血万无一失。
